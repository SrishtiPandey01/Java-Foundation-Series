## Why Loops?

Loops are used when a block of code needs to be executed repeatedly.

Instead of writing the same statements multiple times, a loop allows us to execute them repeatedly based on a condition.

## Types of Loops

### 1. while Loop

The `while` loop checks the condition before executing the loop body.

```java
while (condition)
{
    // statements
}
```

### 2. do-while Loop

The `do-while` loop executes the body at least once because the condition is checked after the loop body.

```java
do
{
    // statements
}
while (condition);
```

### 3. for Loop

The `for` loop is commonly used when the number of iterations is known.

```java
for (initialization; condition; update)
{
    // statements
}
```

## Nested Loop

A loop inside another loop is called a nested loop.

Nested loops are especially useful for:

* Pattern printing
* Matrix operations
* Repeated combinations of values

## break

The `break` statement immediately terminates the nearest loop or switch statement.

## continue

The `continue` statement skips the remaining statements of the current iteration and moves to the next iteration.
